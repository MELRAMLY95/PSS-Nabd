# Living Oman 2040

Exhibition site for a student proposal: a body-inspired resource system for Oman 2040. Made for the International Education Conference in Oman, December 2026.

```bash
npm install
npm run dev
```

Open the local address Vite prints. `npm run build` then `npm run preview` serves the production build.

The public site is published from the `main` branch with GitHub Pages.
